◆ JAVA_HEAP_SLOTS

typedef struct JAVA_HEAP_SLOTS JAVA_HEAP_SLOTS

Java heap slots: the VM takes its heap from one of two slots, malloc'ed at the VM start.

The firmware does not free them when the VM ends; see RamJavaHeapSlots.

◆ RamJavaHeapSlots()

JAVA_HEAP_SLOTS * RamJavaHeapSlots ( void )

Java heap slots (see JAVA_HEAP_SLOTS).

After the VM has ended (RamJavaVMStarted is 0) the blocks can be freed: mfree(raw[i]), then zero heap[i], raw[i], size[i] and the matching RamJavaVMHeaps entry. Without this the Java heap (MBs) stays allocated until a reboot.

Returns
pointer to the slot table

◆ RamJavaVMHeaps()

void ** RamJavaVMHeaps ( void )

VM heap globals (set up by the VM start, "HeapCapacity (%d bytes) too low to start VM").

Entry [1] belongs to heap slot 0, entry [0] to heap slot 1: zero them with the slots.

Returns
pointer to the globals
