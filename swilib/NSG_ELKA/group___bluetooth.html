Search the SDP records of a remote device (what JSR-82 searchServices uses).

The accessor then gets message 0x0F per matching record (+18 u16 exception, +20 record) and 0x10 when the search is over.

Parameters
ohaccessor handle
addrremote address, same layout as for BTA_Conn_New_RFCOMM
uuidsUUID list: { u8 count; u8 allocated; u32 element size = 20; void *elements }, element { u8 type (2 = 128-bit); u8 pad[3]; u8 uuid[16] big endian }; copied
attrsattribute ids to fetch (copied)
nattrsnumber of attribute ids
tidtransaction id
Returns
remote device handle, or an invalid handle on failure

ELKA
